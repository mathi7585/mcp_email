# 📧 mcp_emailsender

**mcp_emailsender** is a robust Python-based email sending service designed for integration with MCP (Modular Communication Platform) systems. With a focus on extensibility and ease-of-use, this project enables developers to send emails—including attachments—programmatically, leveraging modern Python libraries and best practices.

---

## 🚀 Introduction

**mcp_emailsender** simplifies the process of sending emails from your applications using Python. Built on top of the MCP framework, it supports plain text, HTML, and attachments, making it an ideal choice for notification systems, automated reports, and more.

---

## ✨ Features

- 📤 **Send Emails**: Supports sending text and HTML emails.
- 📎 **Attachments**: Easily include file attachments of any type.
- 🔒 **Secure Authentication**: Integrates with Google authentication for secure email delivery.
- ⚡ **FastMCP Integration**: Utilizes FastMCP for high-performance server operations.
- 📝 **Configurable Logging**: Built-in logging for debugging and monitoring.

---

## 🛠️ Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mathi7585/mcp_emailsender.git
   cd mcp_emailsender
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   > **Note:** Ensure you have Python 3.8 or higher installed.

---

## 🚦 Usage

1. **Configure your environment:**  
   Set up your email credentials and relevant MCP configurations as environment variables or in a config file.

2. **Run the server:**
   ```bash
   python server.py
   ```

3. **Send an email:**  
   Use your MCP client or API calls to interact with the email sender service.  
   *(Refer to your MCP documentation for client integration details.)*
